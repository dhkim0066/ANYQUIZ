# 0.2.4: round-04에서 드러난 문서 충돌 정리

- 날짜: 2026-11-24
- 근거: `round-04.md`의 "새로 드러난 문제" 나~자와 "결정 필요" 2~6
- 스킬 버전: 0.2.3 → 0.2.4. 스키마는 그대로다

round-04는 v2.2·0.2.3이 고치려던 것을 모두 확인해 주었다(각주 왜곡 없음, 지시문 한 번, 풀이자 틀 그대로, 밑줄 출력, passage 빈칸, 단어집 세 열). 이번에 고친 것은 그 실행에서 새로 드러난, 문서끼리 어긋나는 곳이다.

| round-04 지적 | 고친 것 |
| :- | :- |
| 나. passage 빈칸: "정답은 바꿔 쓴다"와 "가려서 낸다"가 부딪침 | passage 모드의 정답은 가린 원문 그대로. 낱말이면 `cloze/single-blank`, 구·절이면 `reading/blank-inference`. 요지 문항이 있으면 결론 문장을 통째로 가리지 않는다 |
| 다. 지칭 표시를 적는 법이 세 곳에서 다름 | `__…__`로 통일. 원본이 없으면 대상이 하나일 때 기호 없이, 둘 이상일 때만 ⓐ ⓑ. 표준 발문도 맞춤 |
| 라. 유형을 일부만 지정했을 때 | 지정한 유형을 넣고 남은 자리를 기본 순서의 앞에서부터 채운다. 지칭·함축의 보기는 영어, 내용 일치의 기본 방향은 "일치하지 않는 것" |
| 마. vocab 모드에서 `--stats`가 빈 값 | `--stats`가 글 파일(.txt, .md)도 받는다. 낱말 수와 문장 평균 길이를 낸다 |
| 바. 입력에 이미 단어집이 있을 때 | 단어는 지문·보기 본문에서 뽑는다. 표에 실린 단어를 다시 골라도 되지만 표에만 있는 단어는 뽑지 않는다 |
| 사. 품사 표기 기준이 두 곳에서 다름 | format 모드는 원본 표기, 원본이 없는 모드는 `n.` `v.` `adj.` `adv.` |
| 아. 영어 문제지의 정답지 제목이 한국어 | 정답지 제목과 "정답:" 라벨이 발문 언어를 따른다. 해설 쪽 문구만 해설 언어 |
| 자. `pick_names.py`를 돌릴 조건 | 이름이 붙은 인물을 쓸 때만. 역할로만 부르는 글에는 돌리지 않는다 |
| 차. 사건 순서 한 줄이 기록되지 않음 | format 모드의 마지막 요약에 "지문별 줄거리 표"(원본 한 줄, 새 지문 한 줄)를 붙인다. 사용자가 닮은 정도를 직접 보고 판단하게 하려는 것 |

모두 사용자에게 묻지 않고 정했다. 새 기능이 아니라 이미 정한 동작을 한 가지로 적은 것이라고 보았다. "지문별 줄거리 표"만 새로 더한 출력이다.

## 고치지 않은 것

- **가. 실행끼리 줄거리가 같아진다.** 03의 1·2번은 round-03과, 5번은 round-01·02와 같은 이야기다. 원본과 닮은 지문에 대한 사용자 결정(검사는 시기상조, 생성물을 보고 정한다)과 같은 성격이라 같은 방식으로 둔다. `overlap.py`의 실행 간 비교는 문장만 보므로 이 반복을 보지 못한다(최대 1.6%).
- **카. 단어집의 뜻·품사·수준은 아무도 확인하지 않는다.** 3단계에서 잴 방법을 정한다.
- **타.** 여러 라운드에 걸쳐 열려 있던 세션의 서브에이전트가 옛 CLAUDE.md를 물려받았다. 저장소 결함이 아니다. 다음 실행은 새 세션에서 한다.
- `--words-in`은 입력의 기존 단어집 표에만 있는 단어도 "찾은 것"으로 센다.

## 확인한 것과 못 한 것

회귀(샘플 3쌍, 렌더, 중복률, `agentskills validate`, 훅) 통과. `--stats`에 글 파일과 없는 파일을 넣어 확인. 영어 발문·한국어 해설 샘플의 정답지 제목이 "Answer Key"로 나오는 것 확인.

스킬 실제 호출로는 확인하지 않았다. 3단계 기준선을 잴 때 함께 본다.
