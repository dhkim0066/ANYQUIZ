# 기준선 (스킬 0.3.1, 2026-11-25)

측정 기록은 `round-07.md`다. 이 문서는 그 숫자를 어떻게 읽을지를 적는다.

## 숫자

측정 전용 네 장(`eval/holdout/` 06·08·10·12)을 format 모드로 다섯 번씩, 모두 스무 번 돌렸다.

| 축 | 목표 | 값 |
| :- | :- | :- |
| 다섯 번 모두 통과한 장 | | 4 / 4 (실행으로는 20 / 20) |
| 형식 충실도 (`--compare`) | 100% | 20 / 20 실행에서 실패 0, 주의 0 |
| 정답 정확성 (풀이자 두 겹) | 95% 이상 | 255 / 255 |
| 내용 충실도 (채점자 1~5점) | 평균 4.0 이상 | 4.90 (3점 이하 0문항) |
| 신규성 (원본과 6-gram) | 15% 미만 | 최대 0.8% |
| 실행 간 다양성 (실행끼리 6-gram) | 15% 미만 | 세 장은 미만(2.0%, 7.7%, 7.1%), **한 장은 43.8%** |
| 실행 간 줄거리 가짓수 (5면 모두 다름) | 정한 목표 없음 | 평균 4.15. 스무 자리 중 여덟 자리가 5, 가장 낮은 자리는 2 |
| 토큰 | | 실행당 15.8만 |

PLAN.md 4단계의 종료 조건 넷(형식 100%, 정답 95% 이상, 내용 4.0 이상, 중복률 15% 미만)을 숫자로는 이미 채운다.

## 이 숫자가 말해 주는 것

- 지원 유형으로만 된 처음 보는 문제지에서, 절차가 스무 번 모두 끝까지 돌았고 결과가 스스로와 어긋나지 않았다.
- 정답표가 틀리거나 답이 둘인 문항을, 생성자와 다른 풀이자 둘이 한 번도 찾지 못했다.
- 01~05에서 본 숫자(정답 53/53)는 스킬이 이미 본 문제지라서 나온 것이 아니었다.

## 이 숫자가 말해 주지 않는 것

1. **사람이 본 적이 없다.** 정확도 정의의 "사람 표본"은 한 번도 하지 않았다. 255문항 중 주 세션이 읽은 것은 1문항이다.
2. **통과 조건의 절반은 스킬이 통과할 때까지 스스로 돌리는 검사다.** `--compare`와 독립 풀이는 스킬의 4단계 안에 있다. 다 끝난 생성물이 이 둘을 통과하는 것은 절차가 끝났다는 뜻에 가깝다.
3. **풀이자와 채점자가 생성자와 같은 계열의 모델이다.** 같은 곳을 같이 놓칠 수 있다. 채점자가 255문항에 3점 이하를 하나도 주지 않은 것은 문항이 좋아서일 수도, 채점자가 후해서일 수도 있다. 결함을 일부러 넣은 문제지로 풀이자와 채점자가 그것을 잡는지 본 적이 없다.
4. **지원 범위 밖 문항이 하나도 없는 네 장이다.** 어법·서술형이 섞인 문제지, 줄마다 번호가 붙은 단어 시험지는 공개 장(07·09·11)에서 한 번씩만 봤다.
5. **출력을 그대로 쓸 수 있는지는 보지 않았다.** 이 네 장은 원본과 나란히 놓고 판정한 적이 없다.
6. **format 모드만 쟀다.** passage 모드와 vocab 모드는 round-03·04에서 한두 번씩 돌린 것이 전부다.
7. 생성 스무 번 가운데 아홉 번이 API 오류로 끊겼다가 이어서 돌았다. 결과에 준 영향은 모른다.
