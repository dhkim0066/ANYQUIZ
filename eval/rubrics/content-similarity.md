# 내용 충실도 루브릭 (1~5점)

채점자는 **생성된 문항만** 본다. 원본과 생성 과정은 보지 않는다. 원본의 `exam.json`(유형·수준·소재 태그)만 참고한다.

| 점수 | 기준 |
| :- | :- |
| 5 | 같은 소재·같은 수준. 발문·보기가 자연스럽고 정답이 하나뿐이며 근거가 지문에 명시적 |
| 4 | 위와 같으나 보기 하나가 다소 약하거나 지문 길이·난이도가 살짝 다름 |
| 3 | 소재나 수준 중 하나가 어긋남, 또는 오답 보기 하나가 정답으로도 읽힘 |
| 2 | 유형은 맞으나 정답 근거가 지문에 없거나 모호함 |
| 1 | 유형이 다르거나 풀 수 없는 문항 |

문항마다 점수와 한 줄 이유를 적는다. 3점 이하는 반드시 실패 유형(반대/부분/범위/언급없음/모호/수준/소재)을 태그한다.
