# 영어 과목 규칙

영어 문항에서 "수준이 같다"와 "자연스럽다"를 판단하는 기준입니다. 분석 단계(수준 추정)와 생성 단계(지문·보기 작성) 모두에서 참조합니다.

## 1. 수준 추정 (CEFR)

원본 문제지의 수준은 다음 세 지표로 추정해 `source.json`의 `source_level`에 적습니다. 근거(문장 평균 길이, 눈에 띈 어휘)는 JSON에 적지 않고 사용자에게 보여 주는 분석 요약에 한 줄로 적습니다.

| 지표 | A2 | B1 | B2 | C1 |
| :- | :- | :- | :- | :- |
| 문장 평균 길이 (단어) | 8~12 | 12~17 | 17~22 | 22+ |
| 어휘 | 기초 1,000어 중심 | 2,000어 수준, 일부 학술어 | 학술어·추상어 빈번 | 저빈도 어휘, 관용 표현 |
| 문장 구조 | 단문, and/but | 종속절 1개, 분사구 드묾 | 종속절 2개 이상, 분사구·도치 | 복합 삽입구, 긴 명사구 |

한국 교육과정 대응(참고용, 절대 기준 아님):

| 과정 | 대략적 수준 |
| :- | :- |
| 중학교 1~2학년 | A2 |
| 중학교 3학년 ~ 고1 | A2+ ~ B1 |
| 고2 ~ 수능 | B1+ ~ B2 |
| 수능 고난도(빈칸·순서·삽입 3점) | B2+ |
| TOEFL / 공무원 | B2 ~ C1 |

문장 평균 길이는 직접 세지 말고 `validate_schema.py --stats`의 출력을 봅니다. 수준 값은 `A2+`, `B1+`, `B2+`처럼 사이 단계도 쓸 수 있습니다.

세 지표가 엇갈리면 **어휘를 우선**합니다. 학생이 체감하는 난이도는 어휘가 결정합니다.

문항별 `level`은 기본으로 `source_level`과 같게 적습니다. `--stats`에서 그 지문의 문장 평균 길이가 표의 다른 칸에 들어가거나 어휘가 눈에 띄게 다를 때만 한 칸 올리거나 내립니다. 원본이 "B1–B2"처럼 범위를 적어 두었으면 `source_level`은 낮은 쪽에 `+`를 붙인 값(`B1+`)으로 적습니다.

생성물은 지문 길이뿐 아니라 **문장 평균 길이**도 원본에 맞춥니다(±25%). 새로 쓴 글은 문장이 길어지는 쪽으로 기울기 쉽습니다. 길어졌으면 긴 문장을 둘로 나눕니다.

## 2. 지문 작성

### 길이와 구조

- 원본 지문 단어 수의 ±20% 안에서 씁니다(`validate_schema.py --stats`로 확인). 수능형은 보통 120~180단어.
- 첫 문장 또는 둘째 문장에 주제를 둡니다. 마지막 문장은 결론 또는 주제 재진술.
- 문단 수는 원본을 따릅니다. 원본이 없으면 문단 하나(order 등 구조상 여러 단락이 필요한 유형은 예외).

### 소재

- 기본은 **원본과 같은 소재, 다른 내용**입니다. 원본이 "플라스틱 재활용"이면 새 지문도 환경·재활용 안에서 쓰되 사례·논지·전개를 바꿉니다.
- "소재"는 글이 무엇에 관한 것인지(`topic_tags`)이고, "내용"은 인물·장소·사건·예시·결론입니다. 소재는 유지하고 내용은 전부 바꿉니다. 원본의 줄거리를 이름만 바꿔 다시 쓰는 것은 다른 내용이 아닙니다.
- 인물 이름, 장소, 사물, 전개 방식은 직접 고르지 않고 `scripts/pick_seeds.py`가 뽑은 조합에서 가져옵니다. 맡겨 두면 실행할 때마다 같은 장면(같은 동아리, 같은 물건, 같은 숫자)이 나옵니다. 소재와 어울리지 않는 칸은 버리고, 남은 칸으로 장면을 정합니다.
- 수능·내신에서 흔한 소재: 환경, 기술과 사회, 심리·행동, 교육, 역사적 일화, 경제 상식, 건강, 예술, 과학 상식.
- 피하는 소재: 특정 종교·정치 입장, 폭력, 실존 인물의 사생활, 최근 시사(검증 불가).

### 사실 관계

- **실존 인물·연도·수치·연구 결과를 지어내지 않습니다.** 필요하면 "a researcher", "a 2010s study", "one survey"처럼 익명화하거나 수치를 빼고 씁니다.
- 과학·역사 내용은 교과서 수준의 널리 알려진 사실만 씁니다. 확신이 없으면 그 내용을 쓰지 않습니다.

### 문체

- 설명문·논설문 기본. 수필체는 원본이 그럴 때만.
- 한 문장 안에 새로운 어려운 단어가 2개를 넘지 않게 합니다.
- 수준에 맞는 어휘를 쓰되, 빈칸·정답과 직접 관련 없는 곳에 억지로 어려운 단어를 넣지 않습니다.

## 3. 어휘 수준 맞추기

- 지문의 어휘 중 수준을 넘는 단어는 전체의 5% 이내로 두고, 문맥으로 뜻을 짐작할 수 있게 씁니다.
- cloze 보기와 vocab 표제어는 **정확히 목표 수준**이어야 합니다. 수준보다 쉬운 보기는 정답을 드러내고, 어려운 보기는 운에 맡기게 만듭니다.
- 같은 문제지 안에서 같은 단어를 두 문항의 정답으로 쓰지 않습니다.

## 4. 오답 보기 설계 (영어 특화)

요지·제목·빈칸 추론·내용 추론 문항의 오답은 아래 네 범주에서 고르되, 한 문항에 같은 범주가 두 개를 넘지 않게 합니다. 일치·불일치, 연결어 빈칸, 순서·삽입처럼 오답의 성격이 유형으로 정해진 문항에는 적용하지 않습니다.

| 범주 | 만드는 법 | 예 |
| :- | :- | :- |
| 반대 | 지문 주장의 부정 | 지문: 협력이 효율을 높인다 → 보기: 경쟁이 효율을 높인다 |
| 부분 정보 | 지문 한 문장만 반영 | 예시로 든 사례를 주제처럼 쓴 보기 |
| 범위 초과 | 지문보다 큰 주장 | "모든 산업에서" "항상" |
| 언급 없음 | 소재는 같으나 지문에 없는 내용 | 지문의 단어를 섞어 쓴 그럴듯한 문장 |

cloze 오답은 **같은 품사 + 의미장이 인접한 단어**로 만듭니다. 전혀 무관한 단어는 보기 역할을 못 합니다.

## 5. 발문 관용 표현

`format` 모드에서는 이 표를 쓰지 않고 **원본 발문을 그대로** 씁니다. 아래 표는 원본이 없는 `passage`·`vocab` 모드용입니다.

### `language: ko`

| subtype | 발문 |
| :- | :- |
| main-idea | 다음 글의 요지로 가장 적절한 것은? / 다음 글의 주제로 가장 적절한 것은? |
| title | 다음 글의 제목으로 가장 적절한 것은? |
| blank-inference | 다음 빈칸에 들어갈 말로 가장 적절한 것은? |
| detail | 다음 글의 내용과 일치하지 않는 것은? |
| order | 주어진 글 다음에 이어질 글의 순서로 가장 적절한 것은? |
| insertion | 글의 흐름으로 보아, 주어진 문장이 들어가기에 가장 적절한 곳은? |
| irrelevant | 다음 글에서 전체 흐름과 관계 없는 문장은? |
| summary | 다음 글의 내용을 한 문장으로 요약하고자 한다. 빈칸 (A), (B)에 들어갈 말로 가장 적절한 것은? |
| reference | 밑줄 친 ⓐ가 가리키는 것은? |
| implied-meaning | 밑줄 친 부분에 담긴 의미로 가장 적절한 것은? |
| inference | 윗글을 바탕으로 추론할 수 있는 것은? / ~한 이유로 가장 적절한 것은? |
| meaning-write | 다음 단어의 문맥상 우리말 뜻을 쓰시오. |
| cloze single | 다음 빈칸에 들어갈 말로 가장 적절한 것은? |
| cloze multi | (A), (B), (C)의 각 네모 안에서 문맥에 맞는 낱말로 가장 적절한 것은? |

### `language: en`

| subtype | 발문 |
| :- | :- |
| main-idea | What is the main idea of the passage? |
| title | Which of the following is the best title for the passage? |
| blank-inference | Which of the following best fits in the blank? |
| detail | Which of the following is NOT true according to the passage? |
| order | Which is the most appropriate order of the paragraphs following the given text? |
| insertion | Where would the following sentence best fit? |
| irrelevant | Which sentence does NOT fit the flow of the passage? |
| summary | Choose the best words for (A) and (B) to complete the summary. |
| reference | What does the underlined ⓐ refer to? |
| implied-meaning | What does the underlined part mean? |
| inference | What can be inferred from the passage? / Why did ...? |
| meaning-write | Write the Korean meaning of each word as used in the passage. |
| cloze single | Choose the word that best completes the sentence. |

보기 번호 표기와 보기 언어는 발문 언어로 정하지 않습니다. 원본을 따릅니다(`option_marker`, 문항별 `option_language`). 한국 학교 시험지는 영어 발문에 ①②③④를 쓰거나, 한국어 발문에 영어 보기를 쓰는 경우가 흔합니다.

## 6. 자주 나는 실수 (검증 단계에서 확인)

- 정답 보기만 지문의 단어를 그대로 쓰고 오답은 다른 단어를 쓴 경우 → 정답이 티 남. paraphrase.
- 빈칸 추론에서 빈칸이 세부 정보 문장에 있는 경우 → 중심 문장으로 옮김.
- detail 문항에서 보기 두 개가 지문의 같은 문장을 가리키는 경우 → 하나를 다른 문장으로.
- 지문에 "studies show that 73% of..." 같은 지어낸 수치 → 삭제 또는 익명화.
- 한 문제지에서 정답 번호가 한쪽에 몰림 → 재배치.
- 단어집 예문이 지문 문장과 동일 → 새로 작성.
