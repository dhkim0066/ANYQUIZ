# 측정 방법과 결과

[README](../README.md)의 "얼마나 믿을 수 있는가"에 나오는 숫자가 어떻게 나왔는지 적은 문서입니다. 숫자가 보장하는 것과 보장하지 않는 것을 함께 적었습니다.

## 어떻게 쟀는가

- **문제지:** 만든 사람이 직접 준비한 영어 문제지를 썼습니다. 기출 문제나 남의 문제지는 쓰지 않았습니다. 그중 네 장은 스킬을 고치는 동안 한 번도 들여다보지 않고 측정에만 썼습니다.
- **실행:** 실행마다 새 에이전트가 스킬과 문제지 한 장만 받았습니다. 이전 결과나 비교 기준은 알려 주지 않았습니다.
- **반복:** 같은 문제지를 다섯 번씩 돌렸습니다. 다섯 번 모두 통과해야 그 문제지를 통과로 셌습니다. 한 번 성공한 비율로 세지 않았습니다.
- **다시 풀기:** 생성된 문제지를 정답 없이 별도의 풀이자가 풀었습니다. 답이 정답표와 다르거나 둘이 될 수 있으면 실패로 셌습니다.

## 기준선 (0.3.1, 2026-11-25)

측정 전용 문제지 네 장을 `format` 모드로 다섯 번씩, 모두 스무 번 돌렸습니다.

| 잰 것 | 목표 | 결과 |
| :- | :- | :- |
| 다섯 번 모두 통과한 문제지 | | **4장 중 4장** (실행으로는 20번 중 20번) |
| 형식이 원본과 같은가 (스크립트 비교) | 100% | 20번 모두 실패 0 |
| 정답표가 맞는가 (풀이자가 다시 풂) | 95% 이상 | **255문항 중 255문항** |
| 내용의 질 (채점자 1~5점) | 평균 4.0 이상 | 4.90, 3점 이하 0문항 |
| 원본 문장과 겹침 (여섯 낱말 연속) | 15% 미만 | 최대 0.8% |
| 같은 문제지의 실행끼리 겹침 | 15% 미만 | 세 장은 미만(2.0%, 7.1%, 7.7%), **한 장은 43.8%** |
| 한 번 만드는 데 드는 토큰 | | 약 16만 |

마지막 줄의 43.8%는 한 문장짜리 문항에서 나왔습니다. 두 실행이 거의 같은 문장을 냈습니다.

## 검사 도구가 결함을 잡는가 (2026-11-26)

풀이자와 채점자가 실제로 결함을 잡는지 따로 시험했습니다. 생성된 문제지에 결함 12개를 일부러 넣었습니다.

| 넣은 결함 | 개수 | 풀이자가 잡은 수 | 채점자가 3점 이하를 준 수 |
| :- | :- | :- | :- |
| 답이 둘이 되는 문항 | 4 | 4 | 4 |
| 정답의 근거가 지문에 없음 | 3 | **2** | 3 |
| 정답표가 틀림 | 2 | 2 | 2 |
| 틀린 영어 | 3 | 3 | **0** |
| 합계 | 12 | 11 | 9 |
| 결함이 없는 26문항에 낸 지적 | | 0 | 0 |

- 뚜렷한 정답 오류, 복수 정답, 문법 오류는 풀이자가 잡습니다.
- 풀이자가 놓친 것은 하나입니다. 근거가 지문에 없는데 짐작이나 소거로 답이 하나로 모이는 문항입니다.
- 채점자는 틀린 영어를 깎지 않았습니다. 이 시험 뒤에 채점 기준을 고쳤습니다.
- 넣은 결함은 뚜렷한 것뿐입니다. 미묘한 결함은 시험하지 못했습니다.

## 공개 전 마지막 점검 (0.3.2, 2026-11-26)

문제지 여섯 장, 지문 하나, 입력 없는 단어집 하나를 **한 번씩** 돌렸습니다.

| 잰 것 | 결과 |
| :- | :- |
| 검사를 통과한 실행 | 8번 중 8번 |
| 풀이자의 답이 정답표와 같은 문항 | 68문항 중 68문항 |
| 풀이자의 지적으로 다시 만든 문항 | 0 |
| `passage` 모드: 넣은 지문이 그대로 실렸는가 | 빈칸 한 곳 말고 글자까지 같음 |
| `vocab` 모드: 단어 20개의 뜻과 품사 | 틀린 것 0 (점검을 돌린 쪽이 읽어 확인) |

한 번씩만 돌린 결과입니다. 다섯 번 모두 통과하는지는 이 점검에서 재지 않았습니다.

## 이 숫자가 보장하지 않는 것

1. **사람이 꼼꼼히 채점한 적이 없습니다.** 만든 사람이 네 장의 생성물을 원본과 나란히 읽고 문제를 찾지 못한 것이 전부입니다. 문항 수로 센 것도 아닙니다.
2. **통과 조건의 절반은 스킬이 스스로 돌리는 검사입니다.** 형식 비교와 다시 풀기는 스킬의 절차 안에 있습니다. 끝난 생성물이 이 둘을 통과하는 것은 "절차가 끝까지 돌았다"는 뜻에 가깝습니다.
3. **풀이자와 채점자가 생성자와 같은 계열의 모델입니다.** 같은 곳을 같이 놓칠 수 있습니다.
4. **기준선의 네 장에는 지원 범위 밖 문항이 없었습니다.** 어법, 서술형이 섞인 문제지는 다른 문제지에서 한 번씩만 돌려 봤고, 그 문항의 품질은 잰 적이 없습니다.
5. **`passage` 모드와 `vocab` 모드는 몇 번 돌려 본 것이 전부입니다.** 다섯 번씩 재지 않았습니다. 단어집의 뜻과 품사를 다시 확인하는 검사는 없습니다.
6. **줄거리의 반복은 숫자에 잡히지 않습니다.** 문장 겹침은 문장만 봅니다. 같은 문제지로 여러 번 만들면 문장은 달라도 이야기가 비슷한 지문이 나올 수 있습니다.
7. 기준선의 스무 번 가운데 아홉 번은 중간에 오류로 끊겼다가 이어서 돌았습니다. 결과에 준 영향은 모릅니다.

## 그래서

**생성물은 초안입니다.** 학생에게 주기 전에 정답과 영어를 한 번 읽어 주세요.
