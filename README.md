# ANYQUIZ

본인이 만든 영어 문제지를 넣으면 **같은 형식의 새 문제지**를, 영어 지문을 넣으면 **그 지문으로 만든 문제**를 내 주는 Agent Skill입니다. 교사·강사·학습자가 자기 자료로 변형 문제를 만드는 용도입니다. [Agent Skills](https://agentskills.io) 표준을 읽는 도구(Claude Code, claude.ai, Codex 등)에서 씁니다.

> 상태: 0.3.2, 공개 전 점검 중입니다. 지금까지 잰 것과 재지 못한 것은 아래 "얼마나 믿을 수 있는가"에 적었습니다.

## 할 수 있는 것

| 모드 | 넣는 것 | 나오는 것 |
| :- | :- | :- |
| `format` | 영어 문제지 (텍스트 PDF, 텍스트) | 유형·문항 수·수준·배점·보기 표기가 같은 새 문제지와 정답·해설 |
| `passage` | 영어 지문 | 그 지문을 그대로 실은 문제 (기본: 요지, 내용 일치, 추론, 제목, 빈칸) |
| `vocab` | 영어 글, 또는 수준과 주제 | 단어집 (단어·품사·뜻, 요청하면 예문) |

지원하는 문항 유형은 세 갈래입니다.

| 갈래 | 유형 |
| :- | :- |
| 빈칸 | 낱말 빈칸, (A)(B)(C) 낱말 고르기, 보기 상자에서 골라 쓰기 |
| 단어 | 단어집, 뜻 쓰기, 유의어 짝짓기, 뜻풀이 짝짓기 |
| 독해 | 요지·주제, 제목, 빈칸 추론, 내용 일치, 지칭 추론, 함축 의미, 추론, 글의 순서, 문장 삽입, 무관한 문장, 요약문 |

결과는 문제지와 정답·해설이 나뉜 마크다운이고, 요청하면 Word(DOCX)로도 내보냅니다.

## 설치

### Claude (웹·데스크톱 앱)

Python을 설치할 필요가 없습니다. 스크립트는 Claude 쪽 실행 공간에서 돕니다.

1. [릴리스](https://github.com/dhkim0066/ANYQUIZ/releases)에서 `anyquiz-english-x.y.z.zip`을 받습니다. 압축은 풀지 않습니다.
2. **설정 > 기능**에서 "코드 실행 및 파일 생성"이 켜져 있는지 확인합니다.
3. **플러그인** 화면에서 오른쪽 위의 **추가** → **플러그인 업로드**를 누르고 zip을 넣습니다. (한국어 화면, 2026년 11월에 확인한 순서입니다. 화면이 다르면 **사용자 정의 > 스킬**에서 `+` → "스킬 만들기" → "스킬 업로드"를 찾으세요.)
4. 목록에 `anyquiz-english`가 "추가됨"으로 보이면 끝입니다. 새 대화에서 문제지를 붙이고 말하면 됩니다.

### Claude Code

```bash
git clone https://github.com/dhkim0066/ANYQUIZ.git
pip install pdfplumber pypdf jsonschema python-docx
```

쓰려는 프로젝트 폴더에서 스킬 폴더를 연결합니다.

```bash
mkdir -p .claude/skills
ln -s /경로/ANYQUIZ/skills/anyquiz-english .claude/skills/anyquiz-english
```

Windows에서는 `ln -s`가 복사본을 만듭니다. 명령 프롬프트에서 이렇게 합니다.

```
mkdir .claude\skills
mklink /J .claude\skills\anyquiz-english C:\경로\ANYQUIZ\skills\anyquiz-english
```

세션에서 `/anyquiz-english`를 치거나 "이 문제지와 같은 형식으로 새 문제지 만들어 줘"처럼 말하면 됩니다.

### Codex

저장소의 `.agents/skills/` 아래에 스킬 폴더를 둡니다.

```bash
mkdir -p .agents/skills
cp -r /경로/ANYQUIZ/skills/anyquiz-english .agents/skills/
```

> 개발과 측정은 Claude Code(Windows)에서 했습니다. Claude 앱에서는 zip을 올려 문제지 한 장을 끝까지 만들어 본 것이 한 번입니다(PDF 입력, Word 출력). Codex에서는 아직 설치해 보지 않았습니다.

## 쓰는 법

```
이 문제지(exam.pdf)와 같은 형식으로 새 문제지를 만들어 줘. 문항 수는 원본과 같게.
```

```
이 지문으로 독해 문제 5개 만들어 줘. 발문은 한국어, 보기는 ①~⑤.
```

```
B1 수준 환경 주제 단어 20개로 단어집 만들어 줘. 뜻은 한국어.
```

스킬은 먼저 원본을 분석한 표를 보여 주고 확인을 받은 뒤 만듭니다. 문제지 한 장에 몇 분이 걸립니다.

## 넣을 수 있는 것과 없는 것

- 넣을 수 있는 것: 텍스트가 들어 있는 PDF, 붙여넣은 글, `.txt`, `.md`. 2단 편집 PDF도 읽습니다.
- 넣을 수 없는 것: **스캔한 이미지 PDF, 듣기 문제, 영어가 아닌 과목.** 그렇다고 알리고 멈춥니다.
- PDF에서는 밑줄과 네모 상자가 사라집니다. 발문에 "밑줄 친"이 있으면 스킬이 문맥으로 대상을 짐작하므로, 분석 표에서 한 번 확인해 주세요.
- 정답지가 없는 문제지도 됩니다.

**어법, 서술형처럼 위 표에 없는 유형이 섞인 문제지**도 받습니다. 그 문항도 만들지만, 작성 규칙과 검사 없이 만든 것이라 출력 맨 위에 "지원 범위 밖 문항"으로 번호를 적어 둡니다. 쓰기 전에 그 문항은 꼭 직접 보세요.

## 어떻게 만드는가

1. **분석**: 원본의 형식(유형, 문항 수, 수준, 배점, 발문 언어, 보기 표기)을 정해진 틀로 적습니다. 원본에 없는 것은 지어 넣지 않습니다.
2. **생성**: 그 틀에 맞춰 지문과 문항을 새로 씁니다. 소재는 원본을 따르고 문장은 다시 쓰지 않습니다.
3. **검증**: 세 가지를 합니다.
   - 형식이 원본과 같은지 스크립트가 비교합니다.
   - 원본 문장과 겹치는 정도를 스크립트가 잽니다(여섯 낱말 연속, 15% 미만).
   - 정답을 가린 문제지를 다른 풀이자가 다시 풉니다. 답이 다르거나 둘이 될 수 있으면 그 문항을 다시 만듭니다.
4. **출력**: 두 번 고쳐도 지적이 남은 문항은 빼지 않고 맨 위에 "검토 필요 문항"으로 표시합니다.

## 얼마나 믿을 수 있는가

스킬을 만들 때 쓰지 않은 문제지 네 장을 다섯 번씩, 모두 스무 번 돌려 잰 값입니다(0.3.1, `eval/results/baseline.md`).

| 잰 것 | 결과 |
| :- | :- |
| 다섯 번 모두 끝까지 통과한 문제지 | 4장 중 4장 |
| 정답표가 맞는가 (풀이자 둘이 다시 풂) | 255문항 중 255문항 |
| 원본 문장과 겹침 | 최대 0.8% |
| 한 번 만드는 데 드는 토큰 | 약 16만 |

공개 전 마지막 점검(0.3.2, `eval/results/round-09.md`)에서는 문제지 여섯 장과 지문 하나, 입력 없는 단어집 하나를 한 번씩 돌렸습니다. 여덟 번 모두 검사를 통과했고, 풀이자의 답은 정답표와 모두 같았습니다(63문항). 한 번씩만 돌린 결과입니다.

검사 자체도 시험했습니다. 결함 12개를 일부러 넣은 문제지에서 풀이자는 11개를 잡았고, 결함이 없는 26문항에는 지적을 내지 않았습니다.

**이 숫자가 보장하지 않는 것:**

- 사람이 꼼꼼히 채점한 적이 없습니다. 만든 사람이 네 장을 읽고 문제를 찾지 못한 것이 전부입니다.
- 미묘한 결함은 시험하지 못했습니다. 정답과 차이가 작은 오답, 어색하지만 틀리지는 않은 영어가 그렇습니다.
- 정답의 근거가 지문에 뚜렷하지 않은데 소거로 답이 나오는 문항은 검사가 놓칠 수 있습니다.
- 위 네 장에는 지원 범위 밖 문항이 없었습니다. 어법·서술형 문항의 품질은 잰 적이 없습니다.
- `passage` 모드와 `vocab` 모드는 몇 번 돌려 본 것이 전부입니다. 단어집의 뜻과 품사는 아무도 다시 확인하지 않습니다.

그러니 **생성물은 초안**으로 보고, 학생에게 주기 전에 정답과 영어를 한 번 읽어 주세요.

## 알려진 한계

- 같은 문제지로 여러 번 만들면 지문의 줄거리가 비슷하게 나올 수 있습니다. 문장은 달라도 이야기가 같은 경우입니다. 한 문장짜리 문항은 거의 같은 문장이 다시 나오기도 합니다.
- 새 지문이 원본과 얼마나 닮았는지는 검사하지 않습니다. 대신 지문마다 원본과 새 글의 줄거리를 한 줄씩 나란히 적어 보여 주니, 닮은 정도는 직접 판단해 주세요.
- 영어만 됩니다.
- 표 머리글, 배점표 문구, 채점 기준 문단 같은 세부 모양은 원본과 조금 다르게 나옵니다.
- 원본의 문항 번호와 따로 번호가 매겨진 어휘 표는 문항 번호 하나가 붙어 나옵니다. 배점표의 그 줄도 원본과 다르게 찍힙니다.
- 문제지 머리의 주석, 채점 기준 줄, 지문에 딸린 제목처럼 담을 자리가 없는 요소는 빠지거나 다른 자리에 실립니다.
- 입력 없이 만든 단어집에는 요청한 주제와 수준이 찍히지 않습니다. 낱말이 그 수준에 맞는지 대조할 기준 목록도 없습니다.
- 새 지문은 모델이 쓴 글입니다. 실존 인물과 실제 수치를 쓰지 않게 했지만 사실 관계는 보장하지 않습니다.

## 이용 안내

이 스킬은 **본인에게 권리가 있거나 이용이 허락된 자료**로 학습·출제용 변형 문제를 만드는 도구입니다. 타인의 저작물을 복제하거나 재배포하는 용도로 쓰지 마십시오.

- 올린 문제지와 지문은 사용자의 세션 안에서만 처리됩니다. 이 스킬은 파일을 따로 저장하거나 밖으로 보내지 않습니다.
- 생성물의 검토와 이용에 따른 책임은 사용자에게 있습니다.

## 저장소 구성

| 경로 | 내용 |
| :- | :- |
| `skills/anyquiz-english/` | 스킬 본체. `SKILL.md`, 작성 규칙(`references/`), 스크립트(`scripts/`) |
| `eval/sources/` | 평가용 문제지 아홉 장 (직접 만든 것) |
| `eval/holdout/` | 측정 전용 문제지 네 장. 스킬을 고칠 때는 보지 않습니다 |
| `eval/results/` | 라운드별 기록과 기준선 |
| `PLAN.md` | 단계별 계획과 남은 일 |

스크립트는 스킬이 알아서 부릅니다. 직접 써 보려면 각 스크립트에 `--help`를 붙여 실행하세요.
